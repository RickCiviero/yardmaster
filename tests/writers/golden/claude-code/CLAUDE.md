## Model routing (Yardmaster)

Managed by Yardmaster 1.1.1 (2026-11-23). Edits inside this block are replaced the next time it runs; edit outside it freely.

Delegate each kind of work to the matching subagent:

- `ym-build-and-fix` (opus): Building or changing code over many steps, such as a feature, a bug fix, or a refactor.
- `ym-quick-questions` (haiku): Quick answers and small chores, such as where something is or what a setting does.

Handle in the main session: Planning difficult multi-step work, such as architecture or migration design.
