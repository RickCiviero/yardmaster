## Model routing (Yardmaster)

Managed by Yardmaster 1.1.1 (2026-11-23). Edits inside this block are replaced the next time it runs; edit outside it freely.

Codex cannot change model mid-session. Start it with the profile that matches the kind of work:

- `codex --profile ym-deep-planning` (gpt-6.2-astra): Planning difficult multi-step work, such as architecture or migration design.
- `codex --profile ym-build-and-fix` (gpt-6.2-sol): Building or changing code over many steps, such as a feature, a bug fix, or a refactor.
- `codex --profile ym-quick-questions` (gpt-6-luna): Quick answers and small chores, such as where something is or what a setting does.
